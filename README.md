# final_project_550
 
FastAPI web app for jobs/categories & stats listed under the Bureau of Labor Statistics' (BLS) Occupational Outlook Handbook (OOH). Created a database via web scraping and added endpoints to render the results using SQLModel.

## How to Launch

1. Create virutal environment.
2. Install dependencies:
    pip install -r requirements.txt

3. Start the server:

fastapi dev main.py

4. Open http://127.0.0.1:8000
